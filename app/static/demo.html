Production Agent Demo

Thử một request qua đúng luồng xác thực, giới hạn lượt gọi, ngân sách và lịch sử Redis. Phần trả lời do mock LLM tạo để demo ổn định và không cần khóa nhà cung cấp AI.

Gửi câu hỏi

Khóa chỉ được giữ trong tab hiện tại để gửi request. Trang không lưu vào localStorage.

Giới hạn mặc định: 10 request/phút/user

Kết quả

Nhập API key và gửi câu hỏi để xem câu trả lời.

Trạng thái service

/health · processĐang kiểm tra
/ready · RedisĐang kiểm tra

Nếu /health tốt nhưng /ready lỗi, hãy kiểm tra REDIS_URL và trạng thái Redis. Mở API docs để thử endpoint trực tiếp.

401: thiếu/sai key · 429: vượt rate limit · 402: hết ngân sách tháng · 503: chưa sẵn sàng.
